# Reverse-engineering notes

This repository implements an original interstellar-voyage simulation inspired by the public product concept of Almost Nowhere. It does not copy the site's source code, branding, prose, art, or private services.

## Product mechanics captured

- Wall-clock-linked voyage simulation.
- Separate Earth coordinate time and ship proper time.
- Sublight relativistic velocity using rapidity.
- Propulsion/fuel trade-offs and finite exhaust velocity.
- Shipyard validation for crew, habitat, life support, mass, and shields.
- Distinct real/science-fiction rulesets with explicit fictional flags.
- Shield erosion and fail-closed crew survival.
- Deterministic core independent of the UI framework.
